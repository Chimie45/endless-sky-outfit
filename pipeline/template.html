Credits

Drydock is a fan-made ship & fleet outfit builder for Endless Sky. It is not affiliated with or endorsed by the Endless Sky project.

Game content & art

All ships, outfits, systems, planets, landscapes and sprites are from Endless Sky and its many contributors, parsed and bundled from the game's data and image files.

A few assets use other free licenses · see the upstream copyright and license files for the full per-asset author credits.

Import from Save

Load a ship or your whole fleet straight from an Endless Sky save file (a .txt from the game's saves folder). The file is read in your browser — nothing is uploaded anywhere.

Contributors & Thanks

Drydock is shaped by the Endless Sky community. Huge thanks to everyone who reported bugs, suggested features, and helped test — named here per release.

Edit Save — Rename Ships

Close Endless Sky first — the game overwrites the save while it's running, so edit with it closed and it'll pick up the change next load. The file is read and written entirely in your browser; nothing is uploaded.
